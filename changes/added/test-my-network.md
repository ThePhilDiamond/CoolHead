- **Test my network**, for a Mac that feels slow when nothing on it is busy. It shows what the Mac can say about its connection without asking for any permission (Wi-Fi signal, noise, speed and channel, the DNS server, any VPN or proxy, and which apps are using the network), and runs Apple's own network test only when you press Start test, since the test fills your connection for up to 30 seconds and uses data. It says in plain words whether the network is slow to respond (300 round trips a minute or fewer is poor) or fine.
