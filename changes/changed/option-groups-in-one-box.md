- On a card, an open group of options (One click or Do it yourself) is now one box, with the group's name as its top line and its options inside it, so the options read as part of the group rather than as a second box under it. Folded, the group is the same box with just that line and how many options it holds; open, it no longer says how many, since none are hidden. The arrow that opens a group is lighter than an option's arrow, which acts. The Network page's extra options look the same.
