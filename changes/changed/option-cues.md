- Every option on a card has a small tag for what it does about the problem: Fixes the cause, Helps, Helps later, or Tells you more, beside Caution where an option is risky. The tags sit top right where they fit beside the option's name, otherwise on their own line under it.
- The recommended option no longer has a Recommended label. It's the blue one, first inside its group (One click or Do it yourself), and a line under it says why: "Cool Head recommends this because it helps in one click.", or just "Cool Head recommends this." where there's no reason to give beyond the card's own. The Network page's options are grouped the same way.
- An option Cool Head does in one click that helps is now recommended over one that only tells you more, as it already was over a task: Blender keeping the graphics chip busy recommends Quit Blender, and DisplayLink Manager running long recommends Quit DisplayLink Manager.
- After an option works, it says what was done, and a few seconds later it goes, since it can't be done again, and the next option is recommended. The rest of the options stay, instead of all giving way to the note.
- Each option's name and icon share one line, so its words run the tile's full width.
