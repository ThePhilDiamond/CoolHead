- With Cool Head for Chrome, the memory card's sleep option now says how many tabs it will sleep in its title ("Sleep 12 tabs you are not looking at"), by the extension's own count, and afterwards how much less memory Chrome uses, measured ("Chrome: 5.1 GB → 3.1 GB (2.0 GB less)"), in place of "Frees about 4.0 GB", which counted protected tabs and memory macOS had already squeezed or moved to the disk. The count is said once, in the title, so the card's explanation no longer repeats it. With the extension in more than one Chrome profile, the count is all of them together. When none can sleep, the option says so and is not recommended. The count needs the extension's next version; until then the title gives no figure.
