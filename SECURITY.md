# Security

Please don't report security problems in a public issue. Use GitHub's private reporting instead: on this repository, open the **Security** tab and choose **Report a vulnerability**. You'll get a reply there.

How Cool Head works, so you can judge what is a problem:

- **What it reads.** It runs as your user and reads what macOS lets your user read: details of your own processes (command line, folder, the files they write, the last lines of their logs) and, for other users' processes such as macOS's own, only their name and CPU use. Reading a job's log in Documents, Desktop, Downloads or iCloud Drive may make macOS ask whether Cool Head can access that folder; saying no only means those jobs get less detailed cards.
- **What it stores.** Nothing about what happened. Its settings (notifications, open at login, automatic update checks, Save Battery When Unplugged, the menu bar icon) and your own choices (apps and jobs you mark Always trust, reminders to resume a sync app you paused, and jobs paused until you plug in) are kept by macOS in its standard preferences and login items, on this Mac only. macOS keeps notification text in Notification Center, so notifications never name a process or project.
- **What it keeps in memory.** While running, a short anonymised record of its own activity (which cards appeared and cleared, which buttons were pressed and what happened) for Report a problem: at most 6 hours and 300 entries, never written to disk, gone when it quits.
- **What it sends.** A daily request to GitHub's public API for the latest release, to offer updates (off from the right-click menu). Updates are installed only if their Ed25519 signature matches the key built into the app; see [docs/UPDATES.md](docs/UPDATES.md). Apart from that, nothing by itself. Look it up opens a web search for a process name in your browser. Share this case shows an anonymised report inside the panel; Open in GitHub sends that text to GitHub in the link and opens it in your browser, where it is posted, under your GitHub account, only if you press Submit. Report a problem works the same way, adding the person's own words and that activity record. Neither report holds paths, command lines, file or folder names, log lines, user or project names, or developer Team IDs; on every build, `coolhead selftest` builds a report from a made-up process full of private details and fails if any of them appears.
- **What it can change.** Only your own processes, and only when you press a button. Stop asks first, names the process, and is never offered for macOS's own programs or an app's main program (those get Quit, which lets the app ask to save). Run it cooler and Pause until you plug in don't ask, because each can be undone; a paused job carries on when you plug in, when you press Resume now, when Cool Head quits, and when it next starts, so nothing is left frozen. Security, device management, and VPN software is never offered Stop, Run it cooler, or Quit. Cool Head never changes another app's settings: for Chrome's settings it copies the address for you to paste. Before acting, Cool Head checks the process is still the one the card was about.
