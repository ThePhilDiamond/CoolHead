# Security

Please don't report security problems in a public issue. Use GitHub's private reporting instead: on this repository, open the **Security** tab and choose **Report a vulnerability**. You'll get a reply there.

How Cool Head works, so you can judge what is a problem: it runs as your user, reads information about processes that macOS already lets your user read, and writes nothing to disk; what it needs while running stays in memory. It makes no network connections itself. Look it up opens a web search for a process name in your browser. Share this case shows an anonymised report inside the panel and, if you choose, opens it in your browser as a GitHub issue that you can edit and decide whether to submit; the report never holds paths, command lines, file or folder names, log lines, or user or project names, and `coolhead selftest` checks that on every build. It can stop or slow a process only when you press a button that asks first, and only processes your user owns. It can offer to quit an app only if the app is installed in an Applications folder, and the app then quits normally, asking you to save.
